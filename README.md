# employee-dataset-cleaning
Employee dataset cleaning and preprocessing using Python (Pandas, NumPy)


## Objective
The goal of this project is to clean and prepare raw data for analysis.

## Tools & Technologies
- Python
- Pandas
- NumPy

## Steps Performed
- Checked for missing values  
- Removed duplicate records  
- Verified data types  
- Checked for outliers  
- Ensured data consistency  
- Analyzed dataset structure  

## Output
A cleaned dataset was generated and saved as a CSV file.

## Learning Outcome
Learned how to handle real-world data cleaning tasks.
